# 项目说明

本目录为“数值分析与人工智能综合实验”：以 Adam 优化算法训练小型卷积神经网络为对象，
研究迭代法的数值稳定性、超参数敏感性与梯度计算误差，并给出完整的 LaTeX 实验报告。

## 目录结构

```
ai/
├── 说明.md                        本说明文件
├── 报告/
│   ├── Adam训练CNN实验报告.tex     LaTeX 源文件
│   └── Adam训练CNN实验报告.pdf     编译后的报告（14 页）
├── 代码/
│   ├── Adam训练CNN最终实验.ipynb   最终实验 Notebook（已运行，可直接提交）
│   ├── 报告实验脚本.py             报告所用受控实验（三部分，多种子）
│   ├── 初版实验脚本.py             初版探索实验（单随机种子）
│   └── Adam训练CNN.ipynb          初版实验的 Notebook 版本
└── 实验结果/
    ├── 图表/
    │   ├── 报告实验/               报告正文引用的 6 张图
    │   └── 初版实验/               初版实验生成的 10 张图
    └── 数据表/
        ├── 报告实验/               4 个 CSV 数据表
        └── 初版实验/               初版实验汇总表
```

## 运行环境

- Conda 环境：`jup`（Python 3.11）
- 依赖：`numpy`、`matplotlib`、`pandas`、`scikit-learn`、`torch`（CPU 版）
- 数据集：`scikit-learn` 自带的 Digits（8×8 手写数字），无需联网下载

## 运行实验

在 `ai` 目录下激活环境后执行：

```bash
conda activate jup
python 代码/报告实验脚本.py
```

（若使用 `conda run -n jup python ...` 时遇到 GBK 编码报错，可改用上面的
“先激活再运行”方式，或直接调用 `E:\Anaconda\envs\jup\python.exe`。）

脚本会自动创建 `实验结果/图表/报告实验/` 与 `实验结果/数据表/报告实验/`，
并覆盖写入同名结果文件。初版实验同理：

```bash
python 代码/初版实验脚本.py
```

最终实验的 Notebook 版本为 `代码/Adam训练CNN最终实验.ipynb`，已执行并内嵌运行结果，
可直接提交；在 Jupyter 中打开后顺序运行全部单元格也可重新生成图表与数据表。
初版实验的 Notebook 版本 `代码/Adam训练CNN.ipynb` 同样可顺序运行，结果写入
`实验结果/` 下对应目录。

## 编译报告

在 `报告` 目录下用 XeLaTeX 编译（需要两遍以生成正确的交叉引用）：

```bash
cd 报告
xelatex Adam训练CNN实验报告.tex
xelatex Adam训练CNN实验报告.tex
```

报告中的图片通过 `\graphicspath` 引用 `../实验结果/图表/报告实验/`，
因此请在 `报告` 目录内编译，或在 `ai` 根目录下将首条搜索路径调整为本地路径。

## 实验内容概要

1. **二次型稳定性实验**：20 维病态二次型（条件数 100），比较不同步长 GD、
   动量法与 Adam，验证稳定域 `0 < α < 2/L`、条件数对收敛速度的影响及尺度不变性。
2. **梯度有限差分检验**：用双精度 CNN 比较中心差商与自动微分，扫描步长
   `10^-8 ~ 1`，观察截断误差与舍入误差的折中（最优步长约 `5.6×10^-5`）。
3. **CNN 超参数实验**：Digits 数据集，12 组配置 × 3 个随机种子，
   固定数据划分与批顺序，统计测试损失、准确率和梯度范数（均值 ± 标准差）。
